# 2026-10-21 23:19 — AIS-42 developer how-to (schema → migration → API → admin page)

## What was asked

Write a short how-to for the whole development flow — schema change → `db:generate` → `db:migrate`
→ run the API and the admin app locally → open the API-key page — with the exact `pnpm` commands,
the page URL, and a note that the stored tokens are later read by the AI processing pipeline.
DoD: a newcomer can create and list an API key without help.

## Where it landed and why

`docs/Specs/Local-Development.md` **§6** (the previous "See also" became §7). The ticket suggested
`apps/admin/README.md` as an alternative, but that file does not exist, and a second copy of the
same workflow would drift from the living spec that already documents the per-env files, the
`APP_ENV` flow and the pitfalls.

## Verification (everything in the doc was executed)

```text
pnpm --filter @callback/api build         → nest build, silent success
pnpm --filter @callback/api db:generate   → "No schema changes, nothing to migrate 😴"
pnpm --filter @callback/api db:migrate    → "[db:migrate] migrations applied (bookkeeping: platform.__drizzle_migrations)"
psql \dt platform.*                       → platform.__drizzle_migrations, platform.api_keys
set "APP_ENV=local" && pnpm dev           → "API up — APP_ENV=local (raw=local) … CORS origins: http://localhost:5173,…"
POST /api/api-keys                        → 201
POST /api/api-keys (same identifier)      → 409 "An API key with identifier ... already exists"
GET  /api/api-keys                        → 200 + JSON array
GET  http://localhost:5174/api-keys       → 200 text/html (SPA)
```

One correction that only surfaced by running it: **PowerShell 5.1 `Invoke-WebRequest` fails on the
SPA HTML response** (`NullReferenceException`, the IE engine needs `-UseBasicParsing`), so §6.8 uses
`curl` and mentions the caveat. A naive doc would have shipped a broken snippet.

The two demo rows created during verification (`howto-demo-231833`, `howto-demo-curl`) were deleted;
`platform.api_keys` was left with the single row that predates this session.
