## Decisions worth remembering

- **`Siker` chip added (six filters).** The ticket listed five level filters; the store emits
  `success` too, so it got its own chip instead of being reachable only through `Mind`.
- **Non-modal by design.** No overlay, no focus trap, no scroll lock — `OverlayShell` was *not*
  reused, because a diagnostics side view must not block the page.
- **One side effect only.** A `document` `keydown` listener registered while open, so `Escape`
  works even when focus sits outside the panel.
- **Panel mounted, content conditional.** The panel element stays in the DOM with a `translate-x`
  toggle, so the slide animates both ways and the tab's `aria-controls` never dangles; its children
  render only while open, so nothing hidden is focusable.
- **`z-40`.** Below the modal overlay (`z-50`) and below the toast stack (`z-60`).
- **No state, no data.** Filter, unseen count, `hasMore` and the visible slice are all props; the
  20/50 paging window belongs to AIS-83.
