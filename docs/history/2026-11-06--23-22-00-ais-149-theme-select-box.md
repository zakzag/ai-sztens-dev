## What changed

The combobox is gone. The header now has a **select box**: closed, one button showing the chosen
appearance's **icon + label + chevron**; open, a `menuitemradio` list of the three appearances,
each with its icon. No text input, no filtering, no open/close state for the page to mirror.

## Decisions worth remembering

- **A select beats a combobox for a fixed short list.** AIS-148 had to add `onOpen`/`onClose` ports
  because the combobox filters by its own text. A select has no text, so the problem is removed, not
  managed — and the ports are gone.
- **`SelectMenu` reuses recipes instead of inventing a look**: `buttonVariants` for the trigger,
  `dropdownMenuContentVariants` / `dropdownMenuItemVariants` for the panel. The only new classes are
  the `group` marker, the chevron rotation and the item `gap`/checked accent.
- **`role="menuitemradio"` semantics** come from Radix's `RadioGroup`/`RadioItem`, so `aria-checked`,
  arrow keys, `Escape` and focus return are not hand-written.
- **Trigger name is `"Megjelenés: Sötét"`**, not just "Megjelenés": the visible text must appear in
  the accessible name, and the prefix still tells a screen-reader user what the value belongs to.
- **Icons are back** (`SunIcon` / `MoonIcon` / `SunsetIcon`), on the trigger and on every row; a
  listbox/menu item can host an SVG, a native `<option>` cannot.
