| #   | Decision                                                                                                                                                                           | Why                                                                                                                                         |

| D7  | No new npm scripts are added for the walkthrough                                                                                                                                   | the existing `db:*` and `dev` scripts already cover it; a second entry point would need its own tests                                       |

### The eight steps of §6

1. **Előfeltételek** — Node/pnpm versions, Docker, `pnpm install`, `cp infra/.env.example infra/.env.local` + `pnpm db:up`, `cp apps/api/.env.example apps/api/.env.local` (and the mandatory `DATABASE_URL` line), `pnpm --filter @callback/api build`.
2. **A DB állapotának ellenőrzése** — `psql`/`\dt platform.*` via `docker compose exec`, expected `platform.api_keys`, `platform.__drizzle_migrations`.
3. **Séma módosítás** — where the schema lives (`apps/api/src/db/schema.ts`), the rule that the DB is the source of truth for columns and the code must follow.
4. **`db:generate`** — `pnpm --filter @callback/api db:generate`, expected `NNNN_*.sql` + updated `meta/`, both committed.
5. **`db:migrate`** — `pnpm --filter @callback/api build && pnpm --filter @callback/api db:migrate`, expected `[db:migrate] migrations applied …`; re-running is a no-op.
6. **API + admin indítása** — `set "APP_ENV=local" && pnpm dev` (PowerShell alternative), expected banner + ports 3000/5174/5173.
7. **Az oldal megnyitása és egy kulcs felvétele** — `http://localhost:5174/api-keys`, the five form fields, expected success alert + new row, the 409 path, the “nincs lejárat” case.
8. **Ellenőrzés curl-lel + a token sorsa** — `curl` list/create with expected JSON, and the paragraph explaining that the stored key is read by the AI processing pipeline (never by the browser).
