## 1. A cél egy mondatban

A lista szűrője, rendezése és oldalja **az URL search paraméterében** éljen — link másolható,
vissza/előre gomb, böngésző előzmény. A [`useListParams()`](#3-a-hook---uselistparams) hook a
`react-router` `searchParams`-ból olvas, és **visszainírja** az URL-be, ha valaki módosítja.

## 3. A hook — `apps/admin/src/features/api/use-list-params.ts`

```ts
useListParams(schema) → { params, setParam, resetParams }
```

| Követelmény                                           | Konkrétan                                                                    |
| ----------------------------------------------------- | ---------------------------------------------------------------------------- |
| A séma **paraméterként** jön (nem importálja a hook)  | `schema: z.ZodType<ListQuery>` — több erőforrás is használhatja              |
| Az **érvénytelen** paraméter **defaultra esik**       | `?limit=999` → `20`; `?page=abc` → `1`. **Nem dob, nem üríti az oldalt.**    |
| A defaultok **nem kerülnek** az URL-be                | `setParam('page', 1)` után a `searchParams`-ban **nincs** `page`             |
| `params` = parse-olt query (`z.infer<typeof schema>`) | memoizálva                                                                   |
| `setParam(name, value)` egy mezót módosít             | `page`/`q` módosításakor a lap **1-re** ugrik (a szűrő megváltozott)         |
| `resetParams()` mindent visszaállít                   | `setSearchParams({}, { replace: true })` — `replace`: ne tegjen új előzményt |
| Az érvénytelen paraméter **csendben** esik defaultra  | nincs hibaüzenet, nincs redirect                                             |

### 3.1 A megvalósítás kulcsdöntései

| Döntés                            | Döntés és miért                                                                                                                                                                                                                                            |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hogyan parse-olunk?**           | `Object.fromEntries(searchParams.entries())` → `schema.safeParse(...)`. **NE** `parse()` — az dobna. A `safeParse` hibáját **csendben elnyeljük**, a defaultot a séma adja (a shared oldalon a `default()` a sémában van).                                 |
| **A `sort` mező**                 | api-keys: `createListQuerySchema(['name', 'createdAt'], 'createdAt')`. A statikus `listQuerySchema`-val a `sort` **eltűnik** az URL-ből.                                                                                                                   |
| **Mikor írjuk vissza az URL-be?** | A `setParam` **szinkron** hívja a `setSearchParams`-t (nem `useEffect`) — nincs egy extra render, ahol az URL még ellentmond a state-nek.                                                                                                                  |
| **A `params` memoizálása**        | `useMemo(() => parsed, [searchParams.toString()])`. Különben a `queryKey` minden renderben új → TanStack végtelenül újra-fetchelne.                                                                                                                        |
| **A `queryKey`**                  | Ha a szűrő hatással van a listára: `['api-keys', 'list', params]`. Az `API_KEYS_QUERY_KEYS.list` **statikus** — ezt az AIS-114 módosítja. A kulcsnak **tartalmaznia kell** a szűrőt, és **egy helyen** (`API_KEYS_QUERY_KEYS`) kell definiálni, ne inline. |

## 4. A réteg-szabályok (a [`react.coding-standards.md`](../../.roo/rules/react.coding-standards.md:1) normatív)

| Szabály                                                                    | Az AIS-119-re                                                                                                        |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Importok csak lefelé: `app → pages → features → entities → services → lib` | a hook a `features/api/`-ben van; **a `features/` nem importálhat `pages/`-et**                                      |
| **Nincs** `fetch` a `features/`-ben                                        | a hook **nem** hívja a service-t — az [`useApiKeysQuery()`](#2-amit-már-megkaptál--ne-írd-újra-kész)-dolga           |
| Szerver adat soha nem store-ban                                            | a query a TanStack Query cache tartja                                                                                |
| `useEffect` + `fetch` a komponensben tiltott                               | a hook a `useSearchParams`-t használja (szinkron írás)                                                               |
| Névkonvenció                                                               | `use-list-params.ts` (kebab-case); `*.logic.ts` tiszta függvények; `*.const.ts` konstansok; `*.interface.ts` típusok |
| Exportok                                                                   | **nincs** `export default`; a `features/`-ben **nincs** `export *`                                                   |
| Minden async UI path: loading / empty / error / success                    | a szűrő komponens mutatja ezt — `useApiKeysQuery` adja `isLoading`/`errorSurface`/`refetch`-et                       |
| Nincs színliterál, nincs Tailwind paletta-utility                          | csak `packages/ui` primitívek + token-osztályok                                                                      |


### 5.1 A tiszta logika (`use-list-params.logic.ts`)

A [`react.coding-standards.md`](../../.roo/rules/react.coding-standards.md:1) szerint a parse/fallback
logika **hook nélkül** is tesztelhető. Javasolt felosztás:

| Függvény                               | Feladat                                                           | Teszthető?                                                             |
| -------------------------------------- | ----------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `parseListParams(raw, schema)`         | `Object.fromEntries` → `schema.safeParse`, hiba csendben elnyelve | ✅ (`?limit=999` → 20; `?page=abc` → 1)                                |
| `omitDefaults(query, defaults)`        | a defaultok kimaradnak (a shared `toListQueryParams`-ot hívja)    | ✅                                                                     |
| `serializeListParams(query, defaults)` | query → `URLSearchParams`                                         | ✅ (a shared suite **már** leteszteli; itt a hook viselkedését mérjük) |

## 6. A tesztek (vitest + Testing Library, mock-ok `src/test/mocks/`-ben)

| Teszt                           | Mit fed                                                                                                                       |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Tiszta parse                    | érvénytelen paraméter → default (`?limit=999` → 20; `?page=abc` → 1); **nincs hiba**                                          |
| Defaultok kimaradnak az URL-ből | `setParam('page', 1)` után a `searchParams`-ban nincs `page`                                                                  |
| Hook (React Routerral)          | `MemoryRouter initialEntries={['/api-keys?page=3']}` → `params.page === 3`; a `q`/`page` módosítása **szinkron** ír az URL-be |
| `resetParams()`                 | az URL-ből minden eltűnik (`replace`)                                                                                         |
| `page` reset a szűrőváltozásra  | `setParam('limit', 50)` → `params.page === 1`                                                                                 |

A [`app-router.mock.tsx`](../admin/src/test/mocks/app-router.mock.tsx:1) **már létezik** — használd,
ne írd újra. A mock-ok (`api-error`, `query-client`) a meglévő mintát követik.
