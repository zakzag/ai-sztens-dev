# AIS-171 — `packages/ui`: `PageShell` primitíve + az admin oldalak átállítása

**Date:** 2026-11-08 · **Ticket:** AIS-171 · **Parent:** AIS-170
**Blocks:** AIS-170/2 (edit overlay, AIS-172), AIS-170/3 (törlés, AIS-173)

## 1. Cél

A page-váz (`<section>` + `<h1>` + alcím + opcionális back-link) ma **négy helyen** kézzel
ismétlődik, oldalanként más tördeléssel
([`ApiKeysPage.tsx`](../../apps/admin/src/pages/api-keys/ApiKeysPage.tsx:73),
[`ApiKeyDetailPage.tsx`](../../apps/admin/src/pages/api-keys/ApiKeyDetailPage.tsx:205),
[`PlaceholderPage.tsx`](../../apps/admin/src/pages/PlaceholderPage.tsx:13), valamint a
[`route-registry.tsx`](../../apps/admin/src/app/router/route-registry.tsx:128) két inline `<p>`-je).
Egy primitíve + öt hívás = kevesebb kód, és a következő entitás-oldal nem talál ki hatodik tördelést.

## 2. Döntések

## 3. Lépések

### 3.1 `packages/ui` (új primitíve)

1. `packages/ui/src/components/page-shell/page-shell.interface.ts` — `PageShellProps` (`title: string`,
   `subtitle?: string`, `back?: ReactNode`, `actions?: ReactNode`, `children: ReactNode`), JSDoc-kal.
2. `packages/ui/src/components/page-shell/PageShell.tsx` — D3 szerinti markup; `back`/`actions`
   hiányában **nincs** üres wrapper; a `children` a fejléc alatt renderel.
3. `packages/ui/src/index.ts` — explicit `export { PageShell }` + `export type { PageShellProps }`
   (a lista végére, a meglévő stílus szerint).
4. `packages/ui/test/mocks/page-shell-slots.mock.tsx` — `PageShellBackSlot`, `PageShellActionsSlot`
   (slot-JSX a mockok között, nem a tesztfájlban — ts.coding-standards).
5. `packages/ui/test/page-shell.test.tsx` — lásd §4.

### 3.2 `apps/admin` (markup törlés, nem hozzáadás)

6. [`ApiKeysPage.tsx`](../../apps/admin/src/pages/api-keys/ApiKeysPage.tsx:72) — `<section>`/`<header>`
   helyett `<PageShell title subtitle actions={<Link …/>}>`; a `PlusIcon` + `Link` a page-en marad.
7. [`ApiKeyDetailPage.tsx`](../../apps/admin/src/pages/api-keys/ApiKeyDetailPage.tsx:204) — `PageShell`
   `back={<Link …>}` + `subtitle`; a `<header>` blokk és az `mt-2`/`mt-3` kézi tördelés törlődik.
8. [`PlaceholderPage.tsx`](../../apps/admin/src/pages/PlaceholderPage.tsx:11) — `PageShell`
   (`title="AIsztens — Admin"`, `subtitle`), a `BuildInfoFooter` a `children`-ben; D8 szövegjavítás.
9. `pages/calls/calls.const.ts` + `pages/calls/CallsPlaceholderPage.tsx` — `PageShell` „Hívások”
   címmel és „hamarosan” alcímmel.

    „Nem található” címmel.
